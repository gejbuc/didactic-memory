# Vanilla JS Boilerplate

A minimal, clean boilerplate for vanilla JavaScript projects.

## Project Structure

```
.
├── index.html      # Main HTML file
├── styles.css      # CSS styles
├── script.js       # JavaScript logic
└── README.md       # This file
```

## Features

- Clean HTML structure
- CSS custom properties for easy theming
- Event-driven JavaScript pattern
- Responsive design with modern CSS
- No frameworks or dependencies

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start building!

## Development

Edit the files to customize:
- **HTML**: Add elements in `index.html`
- **CSS**: Update styles in `styles.css`
- **JavaScript**: Add logic in `script.js`

## Browser Support

Modern browsers (Chrome, Firefox, Safari, Edge)
